# Cloud checkpoint: «Библия 2.0» и G-Guide

Дата фиксации: 2026-07-20.

Это переносимый текстовый checkpoint двух связанных рабочих проектов:

1. `bible_2_0/` — рукопись «0→1», карты источников, исследовательские матрицы и QA.
2. `g_guide/` — готовый корпус справочника по символам, который должен питать образный и энциклопедический слой основной книги.

Облачная задача должна сначала прочитать `CLOUD_HANDOFF_BIBLE_2_0.md`, а для отдельной редакции справочника — `CLOUD_HANDOFF_G_GUIDE.md`.

## Жёсткие редакционные требования

- Это не сухой self-help и не юридическая памятка: нужен цельный мифопоэтический текст для интеллектуально развитого русскоязычного мужчины.
- Эзотерика, конспирологические модели, этимология, нумерология, символизм и метафора являются обязательными инструментами книги.
- Не выдавать гипотезу за установленный факт: различать исторический источник, научное знание, спорную гипотезу, авторскую модель и художественный миф.
- Не засорять основной голос повторяющимися предупреждениями и канцелярскими оговорками.
- Никаких секретов, токенов, OAuth-ключей и приватных архивов в репозитории.

## Состояние

Рукопись уже велика и содержательно богата, но не прошла финальный P1-gate. Известные блокеры перечислены в handoff. Старые PDF/EPUB не являются релизными артефактами и намеренно не включены.
