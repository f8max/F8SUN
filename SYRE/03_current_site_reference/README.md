# Current site reference

Это не новый executable baseline. От старого WordPress/jQuery сайта сохранены только:

- RU/EN text export;
- структурированный legacy product/geometry JSON;
- selected product/photo/logo imagery;
- screenshots overview и два mobile captures;
- source URL/hash mapping для изображений.

Старые prices, legal, geography, contacts и availability требуют подтверждения.
Legacy frame renders могут содержать символы, удалённые из clean assets.
