# Исключённые материалы

Исключение означает «не вошло в lean archive», а не удаление из исходной папки.

- Большие aggregate archives и их checksum — дубли.
- `Development/` — generated builds + logs.
- `Evidence/`, stalled run logs, receipts, controller screenshots — QA history.
- Старые root launcher/dashboard — относится к прежней выдаче.
- C1-C5 evidence, source archives и per-concept archives — заменены lean source.
- C2/C5 source — optional experiments; визуально отражены в overview.
- Prototypes-Clean alternatives — V2 уже фиксирует выбранную Drift mechanics.
- Повторные Rama/frames/ZIP — одна canonical copy сохранена в V2 reference.
- `CLEANED_2X` — неподтверждённый alternate derivative.
- WordPress/jQuery runtime, analytics, reCAPTCHA, old fonts и vendor JS/CSS —
  не являются новым tech baseline.
- Raw original project brief — дублирует транскрипт и содержит внутреннюю ссылку.
