# Security policy

## Reporting a vulnerability

Do not disclose security vulnerabilities, credentials, personal data, or
private evidence in a public issue or pull request.

Use GitHub's private security-advisory flow from the repository **Security**
tab when it is available. Otherwise contact repository owner `@f8max` through
a previously established private channel and provide only the minimum
information needed to reproduce the problem.

Include:

- the affected branch, file, or workflow;
- a concise impact statement;
- safe reproduction steps;
- suggested remediation, if known.

Do not include live credentials. If a credential may have been exposed,
revoke or rotate it first, then remove it from the current tree and history as
appropriate.

## Supported state

`main` is the only default supported branch. Product branches and draft pull
requests are works in progress and may change without notice.
